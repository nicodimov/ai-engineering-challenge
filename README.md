# AI Engineering Challenge

Small TypeScript/Vitest repository used for the team's asynchronous AI-assisted engineering workflow benchmark.

## Setup

```bash
npm install
npm test
```

Read [`CHALLENGE.md`](./CHALLENGE.md) before starting.

Before opening your PR, run:

```bash
npm run verify:submission
```

## Important

- Complete the exercise on your own branch: `challenge/<your-name>`.
- Keep `AI_WORKFLOW.md` up to date while working.
- Do not inspect other challenge PRs before submitting your own.
